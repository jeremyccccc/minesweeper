# 在线扫雷

支持跨设备账户、每周最佳、历史最佳和排行榜的网页版扫雷。

## 部署到 Vercel

1. 将本目录提交到 GitHub 仓库。
2. 在 Vercel 中选择 **Add New → Project**，导入该仓库并部署。
3. 打开项目的 **Storage / Marketplace**，添加 **Neon Postgres** 集成并连接到此项目。
4. 在 Vercel 项目的环境变量中确认存在 `DATABASE_URL`（部分旧集成可能显示为 `POSTGRES_URL`）。
5. 重新部署一次。

无需手动创建数据表；首次访问 API 时会自动初始化账户、会话和成绩表。

## 对局与成绩

已登录玩家的新棋盘会在后台领取服务端对局编号。准备期间或网络不可用时仍可立即开始本地练习；练习局不会上传，页面会给出提示。中途登录的成绩从下一局开始记录。

成绩提交包含对局编号及操作记录。服务端核对玩家、棋盘、操作回放和胜利状态，并用服务端开始/完成时间计算排行秒数；一次对局只能记录一次。排行计时至少 1 秒，包含网络传输耗时，因此可能与本地计时略有差异。超过 999 秒会继续正常计时和记录。

最终二选一保护仅在两种雷位都符合所有已翻开数字，且其余旗子均正确时生效。

该校验可阻止直接伪造秒数和未完成棋盘的成绩；浏览器仍持有棋盘信息，不具备阻止自动解题或修改客户端的强反作弊能力。已有历史成绩会保留。

对局编号 24 小时内有效。后台不会自动删除历史对局记录。

运行回归检查：`npm test`。

## 本地开发

复制线上数据库连接地址到本地 `.env.local`：

```text
DATABASE_URL=你的数据库连接地址
```

然后运行：

```bash
npm install
npm run dev
```

不要将 `.env.local` 提交到 GitHub。
